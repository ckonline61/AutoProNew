# Customer mobile preview — 13 October 2026

The customer app launches through Expo SDK 57 with a custom registered entry point, Expo Metro defaults and babel-preset-expo. React, React Native, storage, screens, gesture-handler and safe-area versions match the SDK. Test tooling matches Expo's expected Jest 29 versions.

## Verified
- Expo dependency check passes.
- Strict TypeScript and ESLint pass.
- Six tests pass: five new session regression tests and the pre-existing placeholder test.
- Android and iOS Hermes bundles plus web assets export successfully. These are JavaScript exports, not APK/IPA builds.
- Expo Go manifest serves SDK 57 on the current LAN host.
- Running React Native web preview: login, explicit sample preview, home, bookings, marketplace and profile navigation were checked in the browser.
- Demo sessions create no token, send no login request and are not persisted. Real login parses backend access/refresh tokens, checks the customer role, and registration logs in after account creation. Failed login cannot silently create a fake user.

## Remaining limits
- Physical-device runtime was not verified on an attached phone; no signed APK/IPA was generated.
- Booking, emergency, marketplace, vehicles and address screens still use simulated data, clearly identified by the app banner. This work fixes the mobile preview and authentication setup, not all remaining platform business flows.
- Real API calls derive the development host from Expo or EXPO_PUBLIC_API_BASE_URL. Set a real HTTPS endpoint before a production build. A Metro tunnel does not expose the local backend.
- Browser API CORS origins were added to the ignored backend .env and documented in .env.example. Automatic approval review blocked restarting the backend service; those changes require the next manual backend restart. Native and sample previews do not depend on this browser CORS change.
- npm install reported 58 dependency advisories, including transitive Expo/Metro/test tooling. No forced dependency downgrades or incompatible audit fixes were applied. Passing compatibility and bundle checks does not establish production security readiness.

# PHASE 18 — USED CARS & VEHICLE INSPECTION

## Goal
Build the certified used car marketplace, digital 200+ point inspection engine, lead generation system, and automated inspection report PDF generator.

## Key Tasks
1. Build used car listing data models and APIs: vehicle specifications, odometer, ownership history, pricing, photo gallery, location, and seller info.
2. Implement 200+ point digital inspection schema covering engine, transmission, bodywork, electricals, tires, brakes, and diagnostic scan.
3. Build inspector mobile tool in `mechanic-mobile/` for item-by-item checklist completion, photo evidence capture, and grading.
4. Build branded vehicle inspection report PDF generator with scorecards and issue documentation.
5. Implement used car browsing, filtering, and comparison screens in `web/` and `customer-mobile/`.
6. Build test-drive booking and inquiry lead capture workflows.
7. Write tests for inspection score calculation and PDF generation.
8. Update `PROJECT_STATE.md`.

## Do NOT
- Publish certified inspection badges without complete inspector sign-off.
- Permit unverified or fraudulent vehicle listings to go live without admin moderation.
- Expose direct seller contact details publicly without lead management privacy protection.

## Deliverables
- Used car marketplace and inspection modules in backend.
- Mobile inspection checklist tool for certified mechanics.
- Branded downloadable inspection report PDF generator.
- Used car marketplace UI in customer web and mobile apps.
- Updated `PROJECT_STATE.md`.
